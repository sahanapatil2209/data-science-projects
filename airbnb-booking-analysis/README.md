# Airbnb Booking Analysis Using Exploratory Data Analysis

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on an Airbnb booking dataset to uncover insights related to pricing, room types, neighborhood distribution, and seasonal trends. The goal is to understand key factors that influence Airbnb listings and booking behavior using data visualization and statistical analysis.

---

## Dataset Description
The dataset contains information about Airbnb listings, including pricing, room types, neighborhood groups, availability, and review activity. The data was cleaned and analyzed to ensure meaningful insights and accurate visualizations.

---

## Objectives
- Understand the distribution of listing prices
- Analyze the availability of different room types
- Examine geographical trends across neighborhoods
- Compare pricing across room categories
- Identify seasonal patterns in review activity

---

## Tools and Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Google Colab  

---

## Key Steps Performed
1. Data loading and inspection  
2. Data cleaning and handling missing values  
3. Univariate analysis of price, room type, and reviews  
4. Bivariate analysis between price and room types  
5. Visualization of neighborhood-wise listing distribution  
6. Interpretation of trends and patterns  

---

## Key Insights
- Most Airbnb listings fall within a moderate price range, with a small number of high priced premium listings.
- Entire homes or apartments and private rooms dominate the dataset.
- Shared rooms and hotel rooms are comparatively rare.
- Listings are heavily concentrated in Manhattan and Brooklyn.
- Entire homes or apartments generally have higher prices than private rooms.
- Review activity shows noticeable seasonal trends across months.

---

## Visualizations Included
- Price distribution histogram with KDE
- Count plots for room types and neighborhood groups
- Box plots comparing prices across room types
- Scatter and trend based plots for exploratory insights
